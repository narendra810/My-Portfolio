DisciFlow

A command-line productivity system combining task management, deadlines, Pomodoro sessions and subject-based focus audio.

Python Regex File I/O Pygame

The idea

DisciFlow was built around a simple productivity problem: knowing what needs to be done is not the same as actually sitting down and doing it.

Instead of being only a Pomodoro timer or only a to-do list, DisciFlow combines planning and focused execution into one command-line workflow.

What it does

Task management

Tasks can contain descriptions, due dates and due times, with information persisted to a task file rather than disappearing when the program closes.

Deadline awareness

The application checks stored task timing and can identify tasks whose deadlines have passed.

Pomodoro sessions

Tasks can be connected to focused work sessions, turning the task list into something that helps with actual execution.

Interactive input

Regular expressions are used to parse structured task-related input, allowing the CLI to work with more flexible user input than a rigid command format.

Subject-based audio

Study sessions can use different background frequency presets depending on the subject being worked on.

Focus presets

Physics 15 Hz
Maths 15 Hz
Chemistry 10 Hz
Biology 10 Hz
Other subjects 5 Hz

These are application-specific focus presets, not claims of scientifically validated optimal frequencies.

Implementation

DisciFlow was built in Python using file persistence, regular expressions, date/time handling and pygame's mixer functionality for audio playback.

It was intentionally kept as a lightweight CLI application, allowing the project to focus on program logic instead of spending development time on a graphical interface.
