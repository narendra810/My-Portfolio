Download Manager

A small automation utility that keeps the Downloads folder organised by automatically sorting newly downloaded files according to their extensions.

Python Automation File System

The problem

Downloads folders have a tendency to become a pile of unrelated files: documents, images, archives, installers and everything else ending up in the same place.

Instead of manually organising them, this utility watches the Downloads directory and handles the sorting automatically.

How it works

01 — Watch

The program watches the Downloads folder for newly appearing files.

02 — Identify

When a new file appears, its extension is inspected to determine what type of file it is.

03 — Organise

The file is moved into the appropriate dedicated folder based on its extension.

Example

New download → Check extension → Choose folder → Move file

Why I built it

It is intentionally a small project. Its value is not complexity but usefulness: it automates a repetitive task that would otherwise have to be done manually.

It was also a practical way to work with file-system automation and event-driven behaviour.
